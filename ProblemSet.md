# Riddles - Brain — 100 Level Problem Set (fill-in-the-blank)

Each level = a riddle with a **single-word answer**. The play screen shows blanks =
number of letters in the answer; the player fills the letters. All answers are
**unique**, single words, A–Z only (no articles, no spaces) — ready for the
fill-in-blank format. Difficulty rises: classic riddles early → describe-the-word later.

Format: `Question` → **ANSWER** (letters) · *hint*

---
